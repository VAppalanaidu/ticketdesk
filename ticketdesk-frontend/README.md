# TicketDesk Frontend Application

React 19 + Vite frontend dashboard application for TicketDesk IT Support Ticket Tracker.

## Features
- Pure JavaScript / JSX implementation (`.jsx` / `.js`)
- Strict Indian Mobile Validation (`^[6-9][0-9]{9}$`) with `+91` input group prefix
- Form Header Design System with inline error validation
- Password strength indicator meter & eye toggle
- Character counters for ticket title and description
- Single File Attachment Drag & Drop zone
- Recharts Dashboard Analytics (Status Donut, Priority Pie, Category Bar)
- Quick "Fill Demo Credentials" buttons for Admin, Support, and Employee accounts

## Quickstart
```bash
npm install
npm run dev
```

App URL: `http://localhost:3000`
Backend API Base URL: `http://localhost:8080/api/v1` (configured in `.env`)
